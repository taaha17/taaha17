## Featured Projects

### [Movella DOT → LSL Pipeline](https://github.com/taaha17/movella-dot-lsl-pipeline)
Real-time streaming from Movella Xsens DOT IMU sensors into Lab Streaming Layer: 16 channels at 30 Hz per sensor, with terminal dashboards, bar viewers, and a 3D orientation viewer. Maintained for the ZAT Rhine-Ruhr project.
`Python` · `BLE` · `Lab Streaming Layer` · `uv`

### [HSRW RAG Chatbot "Zero"](https://github.com/taaha17/hsrw-rag-chatbot)
Local-first academic advisor for university regulations. 500+ pages of PDFs ingested into a vector store, hybrid BM25 + semantic retrieval, intent-based query routing, and no data leaving the machine.
`Python` · `LangChain` · `ChromaDB` · `Ollama` · `Gradio`

### [GamesLedger](https://github.com/taaha17/games-ledger)
Full-stack game tracking application: library management, ratings and reviews, secure authentication, and external game metadata via the IGDB API.
`Next.js` · `TypeScript` · `PostgreSQL` · `Prisma` · `Clerk`

### HEXILEXI — AI Word Detective *(lead developer, internal repository)*
LLM-driven vocabulary mentor for primary school children, integrated into the STREEN reading platform ([live](https://streen-app.ais-lab.de/)). Two-step prompt pipeline on local Ollama instances (Gemma 3:12b) and frontend fuzzy-match answer grading in place of LLM-based evaluation. Field-tested across four iterations in two primary schools.
`React` · `TypeScript` · `Ollama`
